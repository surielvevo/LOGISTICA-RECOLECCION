Plataforma de optimización de rutas para recolección de residuos orgánicos.

1. Coloque todos los archivos en la carpeta `public_html` de su hosting.
2. Acceda a `index.php` desde el navegador.
3. Haga clic en el mapa para añadir puntos de recolección indicando nombre y demanda.
4. Ingrese la capacidad del camión y la meta total a recoger.
5. Presione "Calcular Ruta Óptima" para obtener la planificación.
6. El algoritmo utiliza una heurística tipo Sweep implementada en PHP.

Compatible con hosting compartido que soporte PHP 7.4+ (por ejemplo, SiteGround).
